WHAT IT IS
Pharos is a lightweight AI helper that lives in the terminal. It reads
Linux config files, explains what each setting does and which ones are
risky, investigates problems read-only, and proposes fixes as diffs.
It never changes a file without a visible diff, an automatic backup and
the user's explicit approval. "pharos undo" restores the last backup.

WHO IT IS FOR
Students on a fresh Ubuntu install, new developers, and anyone who is
afraid to edit files under /etc or their dotfiles.

HOW BHARATCODE IS USED
- Every model call (explaining files, diagnosing symptoms, proposing
  diffs, tool calls) goes through the BharatCode model API.
- Tools the model can call: list_dir, read_file, search_files,
  service_status, journal_tail, man_page, package_version, propose_edit.
  Nothing else.
- Ubuntu grounding: each request carries the machine's Ubuntu version,
  the model can read the installed man pages, and curated Ubuntu notes
  (src/pharos/notes) are attached when it reads a matching file, so
  advice does not depend on the model's memory of Ubuntu internals.
- The model is behind one small interface (pharos/model.py).
- Secrets (private keys, tokens, .env values, password fields) are
  redacted locally before any request is sent. "--dry-run" shows exactly
  what would be sent.

SAFETY DESIGN
- Read-only by default; every write needs approval.
- Unified diff plus a one-line reason for every change.
- Timestamped backups in ~/.pharos/backups/ and one-command undo.
- Path allowlist with hard deny elsewhere; symlinks resolved.
- Pharos never runs sudo; it prints the command for the user to run.
- The model can only call a fixed set of tools, not a free shell.
